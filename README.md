# Customer Lifetime Value Analysis with Open Source Tools

## Description
This project demonstrates how data scientists can implement End-to-End Machine Learning (ML) systems using open-source tools to perform Customer Lifetime Value (CLTV) analysis.

## Goals/Objectives
*   Demonstrate the process of building a CLTV model.
*   Showcase the implementation of an E2E ML system using open-source tools.
*   Provide a practical example for data scientists looking to apply MLOps principles.

## Scope
This project will cover:
*   Data preprocessing and feature engineering for CLTV.
*   Training and evaluating a CLTV prediction model.
*   Setting up a version-controlled ML pipeline.
*   Experiment tracking and model management.
*   Workflow automation.

## Tools/Technologies
*   **Programming Language:** Python
*   **Data Manipulation:** Pandas, NumPy
*   **Database:** PostgreSQL (for data storage and insights)
*   **Machine Learning:** Scikit-learn
*   **ML Experiment Tracking & Versioning:** MLflow, Weights & Biases
*   **Data Versioning:** DVC
*   **Model Monitoring:** EvidentlyAI
*   **Dashboarding:** Metabase
*   **Real-time Analytics:** Grafana
*   **Workflow Orchestration:** Apache Airflow
*   **Containerization:** Docker
*   **Notebooks:** Jupyter
